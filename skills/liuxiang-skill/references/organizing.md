# 整理字段

`apply` 接受严格 JSON 对象，以下八个字段必须齐全，不能增加字段：

```json
{
  "一句话结论": "不超过100字，归属作者的核心主张",
  "原文核心信息": "3至7条要点，可使用 Markdown 列表",
  "关键数据与案例": "只写原文明确提供的数字、案例及限定条件",
  "待核实": "列出证据缺失、夸张或待查证之处",
  "AI分析": "明确属于 AI 的分析与建议",
  "可二创方向": ["最多三个可借鉴方向"],
  "推荐标签": ["从 read 返回的领域词表选择，最多三个"],
  "内容类型": "教程指南"
}
```

前五个字段为非空字符串，两个列表最多三项。内容类型只能是：行业研究、教程指南、观点分析、案例复盘、工具资料。

使用简体中文。不能把宣传主张转成事实；数字保留时间、币种、单位、口径。缺少数据写“原文未提供具体数据”；没有明显疑点写“暂无明显待核实项（未经外部核验）”。不能在未联网时声称完成核验。

推荐标签只用配置中现有主题，按相关度排序；第一项决定主要目录。无法匹配时留空，保存到待分类。JSON 文件存放在临时工作目录，避免将机器中间数据作为笔记加入知识库。

`apply` 成功后，同一笔记从 `00_收件箱` 移入 `01_外部知识/<主要领域>`，旧版本先保存到知识库之外的备份目录。已经整理的 URL 再次 apply 只返回现有文件，不重新生成。
